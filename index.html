HTML-СПИСКИ

1.Неупорядоченный HTML-список

HTML-тег <ul> определяет неупорядоченный маркированный список.
Неупорядоченный список начинается с тега <ul>.
Каждый элемент списка начинается с тега <li>.
По умолчанию элементы списка обозначаются маркерами.

  • Orange
  • Apple
  • Banana

2. Неупорядоченный список со свойством type

С помощью атрибута type в теге <ul> можно указать тип маркера, который будет использоваться для каждого
элемента неупорядоченного списка.

Пример с type

  • Orange
  • Apple
  • Banana
Тип Вид маркера Пример
disc Черный кружок (по умолчанию) type="disc"
circle ○ Пустой кружок type="circle"
square ▪ Черный квадрат type="square"
