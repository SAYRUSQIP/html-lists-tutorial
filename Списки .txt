Вот что можно добавить для полноты руководства по HTML-спискам:

1. Упорядоченные списки <ol> (обязательно!)
xml
<section>
  <h2>3. Упорядоченный HTML-список</h2>
  <p>Тег <code>&lt;ol&gt;</code> создаёт нумерованный список.</p>
  <div class="demo">
    <ol>
      <li>Первое действие</li>
      <li>Второе действие</li>
      <li>Третье действие</li>
    </ol>
  </div>
</section>
2. Атрибуты <ol> (типы нумерации)
xml
<ol type="A">  <!-- A, B, C... -->
<ol type="I">  <!-- I, II, III... -->
<ol type="1">  <!-- 1, 2, 3... по умолчанию -->
<ol start="5"> <!-- начать с 5 -->
3. Вложенные списки
xml
<ul>
  <li>Фрукты
    <ul>
      <li>Яблоки</li>
      <li>Бананы</li>
    </ul>
  </li>
</ul>
4. CSS стилизация (замена атрибута type)
xml
<style>
.custom-list {
  list-style-type: none;
}
.custom-list li::before {
  content: "★ ";
  color: gold;
}
</style>
5. Описание списка <dl>
xml
<dl>
  <dt>HTML</dt>
  <dd>Язык разметки</dd>
  <dt>CSS</dt>
  <dd>Каскадные таблицы стилей</dd>
</dl>
6. Интерактивные примеры
Кнопки переключения disc/circle/square

🎨 Приоритет добавления:
<ol> — базовый тип списков

Вложенность — частое использование

<dl> — словари/глоссарии

CSS стили — современный подход

Начните с <ol> — логично после <ul>! 👍
